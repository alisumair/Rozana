Rozana / TransactFlow Mobile App
🚀 براہ راست موبائل میں انسٹالیشن (Direct Mobile App)

بغیر کسی فائل ڈاؤن لوڈ کیے اپنے اینڈرائیڈ موبائل پر اصلی ایپ کی طرح انسٹال کریں:

موبائل میں لائیو لنک کھولیں ↗
طریقہ 1 (AI Studio مینو سے APK فائل بنانا):
1. اوپر دائیں کونے میں Settings (⚙️) یا Export بٹن پر کلک کریں۔
2. "Generate APK" منتخب کریں۔
3. سسٹم چند سیکنڈ میں مکمل تیار شدہ .apk ڈاؤن لوڈ لنک اور QR کوڈ بنا دے گا جسے آپ موبائل پر انسٹال کر سکتے ہیں۔
طریقہ 2 (موبائل کروم انسٹالر):
موبائل کے کروم براؤزر میں لنک کھولیں اور اوپر تین ڈاٹس (⋮) دبا کر "Install App" یا "Add to Home screen" پر کلک کریں۔ ایپ موبائل کی ہوم اسکرین پر آ جائے گی۔
طریقہ 3 (Android Studio سے APK):
اوپر سے Export as ZIP ڈاؤن لوڈ کریں یا GitHub پر پش کریں۔ پھر Android Studio میں کھول کر Build > Build APK پر کلک کریں۔
